Cold Start Protocol
⚡ Принцип одночасного старту ("Cold Start"): Розробники та дизайнери стартують одночасно. Розробники НЕ чекають фінальних макетів або рендерів, а дизайнери НЕ поспішають видавати готовий UI без дослідження. Робота розділена на 3 узгоджені такти.
⏱️ Матриця фаз одночасного старту (Cold Start Protocol)
Період Команда дизайнерів (3 дизайнери) Команда розробників (3 розробники) Точка Handoff
Дні 1–3
Підготовка		 Вибір палітри (Primary, Accent), шрифтів. 3D-дизайнер обирає планування 2–3 квартир для моделювання. Розгортання Docker, PostgreSQL 16, Django 5 REST API та каркасу React 18 з Tailwind CSS. Design Tokens
Змінні кольорів у tailwind.config.js
Тижні 1–2
Фаза 1 (MVP)		 User Flow, чорно-білі Wireframes (UX). Моделювання стін та меблів у 3ds Max. Логотип. Auth (JWT), міграції 11 таблиць БД, Swagger API, верстка Wireframe-структур на Tailwind без декору. Wireframes
Фронтендер знає сітку та роутинг
Тиждень 3+
Фаза 2–3		 Повний Figma UI Kit. Текстури та світло у 3ds Max ➔ перші готові 3D-рендери (3–6 шт.). Підключення API, фільтри цін/зручностей, транзакція від Overbooking, вбудовування 3D-галереї. UI Kit & 3D

Деталізація артефактів • 3ds Max Пайплайн • Точки передачі (Handoff)

Деталізація Handoff
🛋️ Дизайнер №1: 3D Designer / 3ds Max (Візуалізація інтер'єрів) Головна фіча MVP
Що створює:
  • 3D-моделювання геометрії кімнат, корпусних меблів, предметів декору та сантехніки в Autodesk 3ds Max.
  • Налаштування реалістичних матеріалів (дерево, скло, текстиль) та освітлення (Corona Renderer або V-Ray).
  • Рендеринг 3–6 ракурсів на кожен об'єкт: вітальня, спальня, кухня, ванна кімната, кутовий ракурс.
  • Постобробка та експорт в оптимізований формат WebP/JPG (1920×1080px, розмір < 300 КБ для швидкої роботи у вебі).
➔ Точка передачі (Handoff): файли передаються з чіткими назвами (наприклад, prop1_living_angle1.webp) розробнику БД (Dev 2) для сідера та верстальнику (Dev 3) для налаштування галереї.
🎨 Дизайнер №2: UX/UI Designer (Дослідження & Design System) UX & Клієнтський UI
Що створює: User Flow, Customer Journey Map, чорно-білі Wireframes, повна Figma Design System & UI Kit (кнопки, інпути валідації, картки помешкань із бейджем "3D Тур", зірковий рейтинг 1–10, інтерактивний календар). Макети: Головна, Каталог із фільтрами, Сторінка житла з 3D-галереєю, Оформлення бронювання, Кабінет гостя.
➔ Вимоги до Handoff: обов'язковий Auto-Layout для компонентів та прив'язка кольорів до токенів Figma.
🏷️ Дизайнер №3: Brand & Dashboard UI Designer (Айдентика & Відео) Бренд & Промо-відео
Що створює: Унікальна назва сервісу, логотип (горизонтальний, фавікон, світла/темна версії), компактний Brandbook, SVG-іконки зручностей, макети кабінету власника житла та адмінпанелі, адаптив під планшети та смартфони, а також проморолик 30–60 секунд із демонстрацією 3D-інтер'єру та бронювання для фінального захисту.
